      How it works

      Chart2Code is the web front end of an academic NLP project: Automated ICD-10 Code Prediction from Clinical Notes Using Machine Learning and Explainable NLP.

      From note to code

      1. Read the note. Typed, pasted, dictated, uploaded as a PDF or text file, or scanned from a photo with on-device OCR (Tesseract).
      2. TF-IDF model. Counts informative words and word pairs, then a Logistic Regression scores all 58 codes. Its weights give the word-level evidence you see highlighted.
      3. PubMedBERT model. A biomedical sentence encoder turns the whole note into a 768-number vector; a second Logistic Regression scores the codes. The same vectors find the most similar training cases.
      4. Combine. Reciprocal rank fusion merges the two rankings. A code both models rank first gets a consensus of 100%.
      5. Flag disagreement. When the two models pick different codes, the note is flagged for careful review.
      6. Human decision. A coder accepts a suggestion or assigns another code. The decision is saved to Coded records.

      Data

      mkurman/clinical-case-icd10-diagnosis: 1,798 de-identified case histories from open-access PubMed Central case reports, one ICD-10-CM code each, with the diagnosis removed from the text.

      The app uses the 58 codes with at least five cases. Training used 368 notes; the 92 held-out test notes are the ones you can load with Load test case, and no note from the same publication was used for training.

      Limitations

      • Only 58 of roughly 70,000 ICD-10-CM codes are supported; any other diagnosis will be mapped to the closest supported code.
      • Codes in the dataset were assigned by an LLM and validated as billable codes, not audited by certified coders.
      • Published case reports are cleaner and more unusual than everyday hospital notes.
      • One principal code per note; real encounters usually need several codes.
      • Academic demo only. Not for clinical or billing use.
